# 猫猫宣传素材

猫猫是 fi_niaR 的原创角色。Q 版插画参考该角色的正面立绘和自然微笑表情，由 GPT Image 生成透明底素材，再以 HTML 排版导出。素材用于猫猫项目的文档和分享预览。代码的 MIT 许可证不涵盖角色形象及宣传图。

- `maomao-chibi.png` 是透明底角色原图。
- `readme-banner.png` 是 1600 × 640 的 README 横图。
- `github-og.png` 是 1280 × 640 的 GitHub Social Preview 图。
- [排版模板](../docs/promo.html)用默认地址渲染横图，附加 `?format=og` 渲染 OG 图。
